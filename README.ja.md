# Nimble Commander 日本語版Fork

[Nimble Commander](https://github.com/mikekazakov/nimble-commander) の日本語UI対応と操作性改善を目指すForkです。メインメニュー、主要なファイル操作ダイアログ、設定画面、検索・接続ダイアログ、ビューアを日本語化しています。未対応の画面は英語で表示されます。

上流のデュアルペイン構成、VFS、既存のファイル操作と英語UIを維持し、小さな変更を積み重ねます。
