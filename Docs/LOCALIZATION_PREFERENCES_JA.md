# 設定画面の日本語化

2026-11-05、macOS 27.0.1 / arm64、Xcode 27.2で実施。

## 対応範囲

[用語集](LOCALIZATION_GLOSSARY_JA.md)に設定、ショートカット、テーマ、レイアウト、エンコーディング等を追加した。

- 一般、テーマ、ペイン、ビューア、エディタ、ターミナル、ショートカット、ツールの8タブ。
- ペイン内の動作、レイアウト、表示、クイック検索、タグ。
- テーマの自動切り替え・読み込み・色分けフィルタ、操作の待ち行列、エディタ追加等の関連シート。
- テーマの色・フォント項目名、ショートカットの動的な操作名、タグ色、確認・説明文。
- 外部ツールの置換構文の説明。構文トークンとタブ区切りは保持。

合計423項目の日本語を追加。設定カタログとアプリ共通カタログを使用し、英語・ロシア語・簡体字中国語の既存エントリを保持した。

コード変更は設定ウインドウのタイトルとテーマ外観のLight/Darkを既存の翻訳テーブルへ接続する部分のみ。外観を保存するenum/tag、設定キー、値、読み込み・保存処理、XIB、初期値、ショートカット、操作コードは変更していない。

## 静的検証

- 各変更カタログのjaを除いたJSONを変更前と比較し、既存言語の文字列・状態・コメント等が同一であることを確認。新規キーはPreferences、Light、Darkの3つ。
- NSString/printfの書式引数と%%を照合し、型と順序が一致。
- 外部ツールの%F、%-10LP、%?、%"Option name"?等の構文を保持。説明文だけを翻訳。
- テーマ色分け表のFocusedは短い「現在位置」とし、実画面で見出しの省略が解消されたことを確認。
- git diff --check成功。生成物・生ログ・認証情報・個人のローカルパスを公開対象に含めない。

## ビルド・テスト

リポジトリ直下で実行:

```sh
xcodebuild -project Source/NimbleCommander/NimbleCommander.xcodeproj \
  -scheme NimbleCommander-Unsigned -configuration Debug \
  -destination 'platform=macOS,arch=arm64' \
  -derivedDataPath /tmp/nc-ja-localized-derived build
xcodebuild -project Source/NimbleCommander/NimbleCommander.xcodeproj \
  -scheme UnitTests -configuration Debug \
  -destination 'platform=macOS,arch=arm64' \
  -derivedDataPath /tmp/nc-ja-localized-derived build
```

両方BUILD SUCCEEDED、終了コード0。既存設定によりアプリはarm64/x86_64のUniversalビルド。

## 表示確認

同じ最終Unsigned Debugアプリを、OSの言語設定を変更せず、`-AppleLanguages '(ja)' -AppleLocale ja_JP`と`-AppleLanguages '(en)' -AppleLocale en_US`で個別に起動した。

| 対象 | 日本語 | 英語 |
|---|---|---|
| 一般 | タブ・ラベル・ボタン確認 | 同じ項目が英語で表示 |
| テーマ | 項目ツリー、色分け表、外観の「ダーク」、自動切り替えシート確認 | ツリー・表・Dark表示を確認 |
| ペイン | 5ページの説明・選択肢・タグ色確認 | 動作ページ・タブ見出し確認 |
| ビューア | 保存項目、エンコーディング等の表示確認 | 同じ項目が英語で表示 |
| エディタ | 一覧、説明文、追加シート確認 | 一覧・説明文を確認 |
| ターミナル | カーソル・シェル・説明文確認 | 同じ項目が英語で表示 |
| ショートカット | 一覧・フィルタ・Fn説明を確認 | 一覧・フィルタ・Fn説明を確認 |
| ツール | 項目と置換構文メニューの日本語説明を確認 | 同じ設定項目が英語で表示 |

各タブはスクリーンショットとアクセシビリティツリーで確認。日本語ではライト外観とダーク外観の画面を確認した。エディタ追加・テーマ自動切り替えシートはキャンセルし、設定初期化・アクセス権リセット・履歴消去・テーマ変更等は実行していない。

## 制約

- ユーザーが保存・編集できるテーマ名、レイアウト名、タグ名、ツール名は翻訳しない。Light、Dark、Short等が名前として表示されることは正常。
- エンコーディング名はOS提供の表記に従う。サイズの数値例、パターン構文、アプリのパス等は保持する。
- テーマの全ツリー項目、全選択肢、全確認ダイアログを個別にGUI操作したわけではない。これらはカタログの完全性とコンパイル・書式を検証した。
- 既存設定の保存・復元機構は単体テストと差分確認で検証。ユーザーの実設定を変更する保存・リセットの実機テストは行っていない。
