# 日本語化 第1段階

## 対象と方針

[用語集](LOCALIZATION_GLOSSARY_JA.md)を作成し、既存String Catalogに日本語を追加した。英語・ロシア語・簡体字中国語の内容、ソース言語、XIB、ファイル操作コード、キー割り当ては変更しない。

- メインメニューと、選択内容に応じたコピー・圧縮等の動的メニュー。
- コピー／移動の入力ダイアログと詳細オプション。
- 同名ファイルの競合ダイアログ。
- 削除確認、フォルダ作成、圧縮、シンボリックリンク／ハードリンク作成・編集。
- Operationsの進捗・エラーメッセージと、共通進捗シートのキャンセル。
- アプリ、Operations、CUIプロジェクトに日本語を登録。言語選択はmacOS/NSBundleの標準機構に従う。

表示名が数字・製品名・ショートカット記号等の項目は原表記を維持。件数の書式引数と型を保持し、日本語の「項目」は数によって変化させない。

## 検証

検証環境: macOS 27.0.1 / arm64、Xcode 27.2。2026-11-05に実施。

### 静的確認

- 日本語エントリ385項目を追加。382項目は翻訳済み（製品名・数字等の原表記維持を含む）、旧登録／試用版の3項目は英語を明示的に保持してneeds_reviewとした。
- 各変更カタログからjaだけを除いたJSONと変更前のJSONを比較し、既存の全言語・キー・コメント等が同一であることを確認。
- 日本語とソースのprintf/NSString書式引数の型・順序を照合し、一致を確認。圧縮件数の%dも保持。
- 部分カタログで内部キーがそのまま出ないよう、パネルの内部キーに日本語または明示的な英語を設定。バイト単位の記号配列と空白は維持。
- 生成されたja.lprojのメニュー、パネル内部キー、Operationsの削除ボタン文言を確認。
- git diff --check成功。ファイル操作コード、XIB、キー割り当て、ライセンスは差分なし。

### ビルド・単体テスト

```sh
xcodebuild -project Source/NimbleCommander/NimbleCommander.xcodeproj \
  -scheme NimbleCommander-Unsigned -configuration Debug \
  -destination 'platform=macOS,arch=arm64' \
  -derivedDataPath /tmp/nc-ja-localized-derived build
xcodebuild -project Source/NimbleCommander/NimbleCommander.xcodeproj \
  -scheme UnitTests -configuration Debug \
  -destination 'platform=macOS,arch=arm64' \
  -derivedDataPath /tmp/nc-ja-localized-derived build
```

両方BUILD SUCCEEDED、終了コード0。アプリはプロジェクト設定に従いarm64/x86_64のUniversalバイナリとなった。日本語リソースを内包した最終Unsigned Debugビルドで表示確認した。

上流スクリプトと同様、ビルドされた各単体テスト実行ファイルを直接実行（FSEvents等のOS機能を利用できるサンドボックス外で実施）。全9本が終了コード0。合計546ケース、124,899アサーション。予期しない失敗なし。

### 表示・操作確認

OSの言語設定を変えず、同じアプリに`-AppleLanguages '(ja)' -AppleLocale ja_JP`および`-AppleLanguages '(en)' -AppleLocale en_US`を指定して個別に起動。

| 画面・操作 | 確認結果 |
|---|---|
| 日本語メニューバー・コマンドメニュー | 日本語の階層と操作名を確認 |
| 日本語コピー・詳細オプション | スクリーンショットで文字切れ・重なりなし |
| 日本語同名ファイル競合 | 上書き、スキップ、両方を保持、末尾に追加、中止を確認。中止後に既存fixtureの内容が不変であることを確認 |
| 日本語移動 | 名前変更／移動先の文言とボタンを確認してキャンセル |
| 日本語フォルダ作成 | 文言とレイアウトを確認。一時領域に日本語名フォルダを作成できた |
| 日本語削除 | ゴミ箱と完全削除の別々のボタンを確認。どちらもキャンセルし、ファイルは削除していない |
| 日本語圧縮 | 保存先、パスワード、圧縮・キャンセルの表示を確認してキャンセル |
| 日本語シンボリックリンク作成 | 文言とレイアウトを確認。一時領域にリンクを作成し、is_symlinkで確認 |
| パネルの内部表示キー | 最終ビルドで「上へ」の表示を確認。内部識別子は表示されない |
| 英語メニュー・コピー・完全削除・フォルダ作成 | 英語で表示されることを確認。確認ダイアログはキャンセル |

GUI操作はすべて専用の一時fixtureを対象とした。ハードリンク作成・リンク編集・全エラー分岐のGUI表示までは未確認（カタログ生成と書式の検証は実施）。

表示確認中、一度アプリの再起動後に画面取得がタイムアウトした。検証用プロセスを終了して再起動すると回復し、最終日本語／英語ビルドで上記確認を完了した。原因は特定していない。

## 今回の制約

- 全画面の日本語化ではない。設定画面、一括改名の詳細UI、属性変更の詳細UI、接続・検索ダイアログ、ビューア等は今後の段階で対応する。
- ツールバーの説明やユーザー定義の表示モード名等に英語が残る場合がある。
- OSやVFSが提供するエラー説明、外部アプリ名、パス、ファイル名は翻訳しない。
- 削除確認の本文は既存の共通文言で、ゴミ箱／完全削除の違いは操作ボタンで明示する。操作選択や既定値は変えていない。
- 未署名アプリの特権ヘルパーや追加権限は検証対象外。リリースやバイナリ公開は行わない。
