# 日本語UI用語集

英語のソース文字列をキーとし、既存String Catalogに`ja`を追加する。英語や他言語の訳、操作の条件、キー割り当ては変更しない。製品名、プロトコル名、UNIXフラグ、ショートカット記号は原表記を維持する。

| 英語 | 日本語 | 用法 |
|---|---|---|
| File | ファイル | メニュー、ファイルそのもの |
| Folder / Directory | フォルダ | 通常のUI。パスや内部識別子は変更しない |
| Item | 項目 | ファイル・フォルダをまとめた表現 |
| Pane / Panel | ペイン | 左右のファイル一覧 |
| Opposite Panel | 反対側のペイン | 操作対象に対する他方 |
| Copy | コピー | 元を残す操作 |
| Move | 移動 | 元の場所から移す操作 |
| Rename | 名前を変更 | 同じ場所での名前変更 |
| Rename/Move | 名前を変更／移動 | 既存の共通操作をそのまま表す |
| Paste | ペースト | macOSの編集操作に合わせる |
| Cut | カット | 既存メニューの翻訳。新しいファイル切取機能は追加しない |
| Delete | 削除 | 一般表現。完全削除とゴミ箱を混同しない |
| Delete Permanently | 完全に削除 | 復元可能なゴミ箱操作とは区別 |
| Move to Trash | ゴミ箱に入れる | macOSのゴミ箱操作 |
| Overwrite | 上書き | 既存項目を置き換える |
| Overwrite Older | 古い項目のみ上書き | 条件に合わない項目はスキップ |
| Keep Both | 両方を保持 | 既存の重複回避動作 |
| Append | 末尾に追加 | ファイル内容の追記 |
| Skip / Skip All | スキップ／すべてスキップ | 現在の項目／以降の該当項目 |
| Abort | 中止 | 実行中の処理を中止 |
| Cancel | キャンセル | ダイアログを取り消す |
| Retry | 再試行 | 失敗した処理を再実行 |
| Symbolic Link | シンボリックリンク | リンク自体とリンク先を区別 |
| Hard Link | ハードリンク | シンボリックリンクと区別 |
| Extended Attributes | 拡張属性 | xattr |
| File Times | ファイルの日時 | 作成・変更等の日時情報 |
| Ownership | 所有者情報 | UNIXの所有者・グループ情報 |
| Verify | 検証 | コピー結果の検証 |
| Compress / Archive | 圧縮／アーカイブ | 操作／生成ファイル |
| Favorites | よく使う項目 | 登録した場所 |
| Hidden Files | 隠しファイル | 表示設定 |
| Preferences / Settings | 設定 | 設定画面とその項目 |
| Hotkeys | ショートカット | キー割り当て。ファンクションキーはF1等を指す |
| Theme | テーマ | 保存済みのテーマ名は翻訳しない |
| Layout | レイアウト | 保存済みのレイアウト名は翻訳しない |
| Focused | 現在位置 | 色分け表の短い見出し。選択済みの項目とは区別 |
| Encoding | エンコーディング | 文字コードの設定 |
| Source / Target | 元／対象 | 外部ツールのパラメータ説明。構文自体は変更しない |
| Admin Mode | 管理者モード | 権限取得の仕様は変更しない |

## 表記規則

- 続きの入力があるメニューは「…」を使う。元の操作が即時実行の場合は追加しない。
- ファイル名を文中に埋め込む場合は「」で囲む。入力値そのものは変更しない。
- `%@`、`%d`、`%lu`等の書式引数は型と順番を保持する。日本語は数にかかわらず「項目」を使う。
- ボタンは短い動詞句とし、破壊操作は「完全に削除」など意味を明確にする。
- ショートカット、ファイル名、拡張子、パス、パターン構文は翻訳しない。
- 未翻訳の画面は既存の英語へフォールバックする。英語UIも独立して確認する。
